{% comment %} Gabarit de base des courriels — MADE IN YEUMBEUL NORD ==================================================== Adapté des gabarits du projet Yessal Gui, dont la structure est conservée : tableaux HTML, largeur fixe de 600 px, styles en ligne, correctif MSO pour Outlook. C'est la seule construction qui tienne dans les clients de messagerie, qui ignorent la moitié du CSS moderne. **Les couleurs sont en dur, et c'est inévitable** : aucun client de messagerie ne lit les variables CSS, donc `var(--ax-accent)` n'y afficherait rien. Elles sont réunies ici, dans ce seul fichier, pour que la bascule reste un geste unique le jour où la charte sera arrêtée. Les valeurs reprennent l'accent natif du template Vireo — verdigris #1E856C — conformément au gel de charte (CLAUDE.md §3) : rien n'est inventé. Accent #1E856C verdigris natif de Vireo Accent foncé #166B57 même teinte, pour le survol et les liens Fond de page #EEF2F1 Surface #FFFFFF Texte fort #16211E Texte courant #47544F Texte discret #7D8A85 Surface douce #F1F7F5 encarts Bordure #DFE7E4 Les illustrations sont **jointes au message**, pas chargées depuis un serveur : `src="cid:…"`. Un client qui bloque les images distantes — la plupart le font par défaut — n'afficherait rien, et la plateforme doit tenir sans connexion.
